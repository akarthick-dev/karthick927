01 AI Companion · Voice Synthesis · FastMCP Systems 2024—Present

Sana AI

Most conversational assistants remain trapped inside passive, transactional web chat boxes. Sana was engineered to explore an active personal companion that unifies real-time voice conversation, 3D spatial presence, and autonomous tool execution via Model Context Protocol (MCP).

Powered by a Python/FastAPI backend with Groq-accelerated LLM inference, Sana evaluates user requests, preserves context across multi-turn dialogues, and executes local system tasks — such as file inspection, shell queries, and live device telemetry — through standardized, sandboxed tool definitions.

System Architecture: Sub-second speech-to-text pipeline using faster-whisper with Voice Activity Detection (VAD) coupled with streaming ElevenLabs audio synthesis and a WebGL 3D character avatar rendered via Three.js.
  • Sub-second conversational latency orchestrated through Groq Llama inference
  • Extensible tool dispatch protocol inspired by Model Context Protocol (FastMCP)
  • Integrated voice pipeline with local Whisper speech recognition and streaming TTS
  • Autonomous system execution: local file reading, command delegation, and status queries

RAG Pipeline

Standard language models struggle with private domain information and frequently hallucinate on unindexed data. This Retrieval-Augmented Generation service allows developers to ingest custom documents (PDFs, Markdown, raw text) and pose questions that are answered using grounded, factual citations.

Built with Python, LangChain, and ChromaDB, the pipeline ingests source documents, chunks text with semantic boundary preservation, computes dense vector embeddings, and performs sub-millisecond similarity lookups to retrieve relevant context snippets prior to prompt assembly.

Production Backend: Deployed as a high-performance RESTful API using FastAPI, with /upload and /ask routes strictly typed with Pydantic schemas and cosine distance thresholds to suppress irrelevant passages.
  • Semantic text chunking using RecursiveCharacterTextSplitter with token overlap
  • Vector indexing and cosine similarity search powered by ChromaDB
  • Context-grounded prompt assembly ensuring verifiable, citation-backed answers
  • Asynchronous RESTful API endpoints (/upload, /ask) with Pydantic payload validation

03 Web Graphics · 3D Avatar Experience · Three.js 2024

SanaSite

An exploration into interactive frontends and real-time graphics on the web. SanaSite renders the Sana companion character directly inside modern browser windows using Three.js and WebGL, bridging the gap between static web portfolios and spatial digital presence.

Features a custom lighting rig (ambient, directional, and subtle rim lights) that dynamically flatters the character model while keeping GPU draw calls and memory consumption minimal for fluid 60 FPS performance.

  • Real-time WebGL rendering with optimized asset payloads and texture compression
  • Interactive orbit camera controls and responsive viewport aspect scaling
  • Tailored lighting environment styled to complement the editorial monochrome theme
  • Native Three.js architecture without heavy external runtime dependencies
